## About
Ini adalah tugas projek RPL kelas 11 'kelompok', membuat website manangement perpustakaan untuk dipakai disekolah kita sendiri sejauh ini fitur fitur nya ada:
- Login Admin
- Login Siswa
- Data Buku
- Peminjaman Dan Pengembalian
- Perhitungan Denda Otomatis
- Pencarian Buku
- Barcode Kode Buku
- Laporan Peminjaman

Status: On Going


## Tech Stack
- PHP
- MySQL (XAMPP Environment)
- Html
- CSS
